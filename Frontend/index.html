About the Project

Bioactive Molecule Prediction Using XGBoost

XGBioactive is a machine learning-based drug discovery project designed to predict the bioactivity of chemical molecules against the COX-2 target protein.

The system uses molecular descriptors calculated using RDKit and an Extreme Gradient Boosting model to classify molecules as active or inactive.
